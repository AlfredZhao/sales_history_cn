# sales_history_cn
主要修订：针对 Oracle 提供的 sales_history 示例数据进行中文化，并支持在安装时按“最近 N 个完整自然年加本年截至当天”或自定义日期范围生成确定性的事实数据，以及在既有 SH 模式中安全地按日期连续追加。

适用场景：仅用于个人测试、PoC场景

作者: Alfred Zhao

日期: 2026-09-09


## 具体说明: 

1. times、sales 和 costs 不再装载原始事实文件，而是在用户选择的完整日期范围内从头生成；默认生成最近 3 个完整自然年加本年截至执行日的数据。COSTS 按产品、日期、促销和渠道的组合粒度生成。promotions 按自然月生成短期活动，销售只关联当日有效的促销或“无促销”，不再装载旧 promotions.csv。

2. times 按中国自然日历生成：周一为一周第一天，财年等于自然年；日期范围可自动扩展至未来。

3. 国家、客户、产品、促销及补充人口统计维度均为中文展示数据；客户使用中国本土模拟姓名、地址、电话和邮箱。

4. 相同输入始终产生相同的事实数据，年化约 20 万条 sales 记录；`sh_append.sql` 自动从现有最大日期的下一天连续追加，避免重复事实数据；支持 Oracle Database 19c+（AL32UTF8）及 SQLcl 26.1.2.0。

5. 初始化与追加共用 `SH_DATA_GENERATION` 包；提交前强制校验销售及成本的促销有效期、日期覆盖和每日销售行数。此版本需重新初始化，不提供旧数据修复。

详细安装、参数说明、校验 SQL 和卸载说明见：[使用手册](docs/使用手册.md)。
